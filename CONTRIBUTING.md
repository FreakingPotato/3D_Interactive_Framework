# Contributing

Start with a small issue or example showing the data you want to explore. Good first contributions include a new non-cell dataset adapter, clearer interaction feedback, performance measurements on ordinary laptops, accessibility improvements, and procedural sound presets.

Keep reusable interaction code separate from domain assumptions. Explain coordinate units, sampling intervals, component identities, provenance and missing information. Never invent scientific events to fill a visual gap. Provide a reproducible example and test the behavior your change affects.

Camera processing must remain on-device by default. Do not add analytics or camera uploads. Keep large datasets and solver environments out of Git history; contribute compact licensed samples with checksums and attribution.

Original contributions are Apache-2.0 unless explicitly agreed otherwise. Preserve third-party licenses and applicable NOTICE entries. Refer to `docs/ADAPTERS.md` and `docs/LOCAL_DEPLOYMENT.md`.
